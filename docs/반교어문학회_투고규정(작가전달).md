# 반교어문학회 『반교어문연구』 논문투고규정 (작가 전달 전문 요약)

- A. 범위·자격: 국어국문학 및 유관 분야. 회원(편집위 결의로 비회원 가능). 동일인 연속 투고 지양
- B. 절차: 마감까지 편집위원회 제출(온라인 http://journal.bangyo.or.kr), 지나면 다음 호. 연회비 + 심사료 6만(환불 없음). 주소·연락처·소속·영문 성명 첨부. 게재 시 온라인 출판 저작권 양도 서명. 게재(예정)증명서는 ‘게재’ 판정 후. 학회지 1부 + 별쇄본 10부
- C. 작성: 한국어, 한자·알파벳 괄호 병기(인용문·각주는 노출 가능). hwp 제출, 이미지 300dpi. 분량 논문 150장 이내(기타 100장), 초과 판면 장당 2만 원
- D. 체재: 제목, 필자명, 차례, 본문, 참고문헌. 연구논문은 차례 뒤 국문초록·주제어, 참고문헌 뒤 Abstract·Key Words. 초록 10장 이내(영문 권장 7~10장). 논문은 게재지 시작·끝 면 명기
