# 『비평문학』 제101호 원고 모집 요지 (한국비평문학회, 2026)

- 투고와 동시에 **연회비 4만 + 심사비 6만 = 10만 원**을 마감 전 본인 명의 입금(미입금 시 심사 의뢰 안 함). 계좌는 학회 공지 참조- 주제 유의: 학위논문·기발표 논문과 유사하면 게재불가. 외국문학·대중문화는 국문학과의 연관성 고려. 동시대 작가·작품은 가급적 피할 것
- 원고: **학회지 규격 파일**에 맞춰 작성, **학회지 양식 설명** 파일로 각주·참고문헌 작성. 투고 시 저자명(소속) 삭제
- 체제: 제목, 국문초록, 국문주제어, 본문, 참고문헌, 영문 제목, 영문초록, 영문주제어. 국문초록 1쪽 이내, 영문초록 2쪽 이내(규격 기준)
