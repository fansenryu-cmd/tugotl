# 투고틀 글꼴 안내 (2026-10-14 생성)

투고틀은 글꼴 파일을 포함하지 않습니다(글꼴은 저작권이 있는 소프트웨어라 임의로 배포할 수 없습니다). 산출 HWP에는 학회 양식·규정이 지정한 **글꼴 이름**이 그대로 기록되므로, 그 글꼴이 내 PC에 없어도 파일은 정상이며 한글이 비슷한 글꼴로 화면에 보여 줄 뿐입니다. 학회 편집부 PC에는 해당 글꼴이 있으므로 투고에는 문제가 없습니다. 다만 **미리보기·인쇄를 정확히 보려면** 아래 글꼴을 설치하면 됩니다.

## 글꼴 구하는 곳

- **윈도우 기본**: 바탕·돋움·맑은 고딕·Times New Roman — 윈도우에 기본으로 있습니다.
- **무료 배포**: KoPubWorld(한국출판인회의 kopus.org), 나눔글꼴(네이버 hangeul.naver.com), 아리따(아모레퍼시픽), Noto·본명조(구글·어도비).
- **상용**: 윤명조·윤고딕(윤디자인), 산돌(산돌구름), SM 신명조·중고딕(직지소프트) — 구매하거나 구독해야 합니다. 없으면 설치하지 않아도 되고, 화면 확인용으로는 한컴 번들의 HY신명조·HY중고딕이 가장 비슷합니다.
