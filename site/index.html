원고를 올리고 학회지를 고르면, 그 학회의 바탕틀과 규정에 맞춘 HWP를 만듭니다. 내장 학회 190곳, AI 없이 규칙으로만 동작합니다.

A rule-based, offline formatter for papers submitted to Korean (KCI-listed) journals. Upload a manuscript, pick the journal, and get an HWP laid out to that journal’s template and rules. 190 journals built in. No AI, no server — nothing leaves your device.

웹에서 바로 열기 · Open in browser 내려받기 · Download (one offline HTML)

약 30 MB. 열어 둔 뒤 인터넷을 끊어도 동작합니다. 내려받은 파일은 더블클릭으로 브라우저에서 엽니다.
About 30 MB. Keeps working offline once opened; open the downloaded file in Chrome or Edge. The interface is in Korean: choose the journal, drop the manuscript, press 적용 (Apply), then 저장 (Save).

휴대폰에서 쓰기. ‘웹에서 바로 열기’로 연 뒤 브라우저 메뉴의 홈 화면에 추가(아이폰 사파리: 공유 → 홈 화면에 추가)를 누르면 앱처럼 설치되고, 한 번 연 뒤에는 인터넷 없이도 열립니다. 원고는 파일 앱·드라이브에서 고르고, 결과는 저장하거나 ▾ 메뉴의 공유하기로 파일 앱·메신저에 바로 보냅니다.On a phone. Open it in the browser and use Add to Home Screen (iPhone Safari: Share → Add to Home Screen) to install it as an app that opens offline. Pick the manuscript from Files or a cloud drive, and save the result or send it with 공유하기 (Share) in the ▾ menu.
